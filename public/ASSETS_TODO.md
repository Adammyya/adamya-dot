# Assets to add before deploying

This folder is served as-is at the site root. Drop these in to complete the
portfolio (none are required for the site to run — it works fine without them):

- `photo.jpg` — your professional photo. Once added, set `photoUrl: "/photo.jpg"`
  in `src/data/portfolioData.js` (it currently shows your initials instead).
- `resume.pdf` — your resume. The "Download Resume" buttons already point to
  `/resume.pdf`, so just drop the file in.
- `og-image.png` — a 1200×630 image used when the site is shared on social
  media (referenced in `index.html`).

You can delete this file once you're done.
